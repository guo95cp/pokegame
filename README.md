# 영칼로리포케 만들기 — 전체 27종 연결용 코드

## 실행
1. VS Code에서 이 폴더를 엽니다.
2. 기존에 사용하던 이미지 파일을 아래 경로에 복사합니다.
3. `index.html`을 브라우저에서 열거나 VS Code Live Server로 실행합니다.

## 이미지 경로
- `images/background.png` : 배경 (기존 배경 이미지)
- `images/bowl.png` : 기본 야채가 담긴 그릇 (기본 야채 영양 계산 제외)
- `images/trays/` : 스테인리스 통 재료 27종
- `images/ingredients/` : 투명 배경 합성용 재료 27종

**두 재료 폴더의 파일명은 동일해야 하며 `.png` 확장자를 사용합니다.**
`P두부.png`는 이름이 P로 시작하지만 3단계 토핑에 표시됩니다.

## 수정할 파일
- `data/nutrition.js`: 실제 영양성분 및 1회 배치 중량. **현재 값은 모두 테스트용 가상 수치입니다.**
- `data/ingredients.js`: 단계 분류, 재료명, 재료별 화면 표시 크기 (`size`).
- `style.css`: UI 크기/위치/색상/재료 선택창 레이아웃.
- `game.js`: 드래그, 재배치, 초기화, 결과 저장 동작.

## 동작 규칙
- 4단계: C(2) → V(8) → 토핑(9, P두부 포함) → 메인토핑(8)
- 동일 재료 여러 번 드래그 가능, 총개수 제한/표시 없음
- 배치된 재료 재이동 가능, 마지막으로 움직인 재료가 맨 위
- 재료 중심점이 그릇 내부에 있어야 배치 가능
- 그릇 밖에 놓은 신규 재료는 추가되지 않음; 기존 재료는 원위치
- 전체 초기화는 확인창, 결과 화면 다시 만들기는 즉시 초기화
- 빈 그릇도 완성 가능, 결과 PNG에 로고 문구/포케/영양성분 포함

## 주의
- 파일이 없는 재료는 선택창에 이미지가 표시되지 않습니다. 해당 파일을 복사하면 됩니다.
- `images/bowl.png`가 없으면 그릇을 그릴 수 없습니다.
- 게임의 무제한 배치는 기능적 제한이 없다는 뜻이며, 매우 많은 이미지를 배치하면 기기 성능에 따라 느려질 수 있습니다.
- PNG에 들어가는 YOUNGKCAL은 텍스트 로고입니다. 실제 로고 이미지로 바꾸려면 결과 카드 그리기 코드를 수정해야 합니다.
